## 🚀 Android 네이티브 개발을 목표로 성장하는 모바일 앱 개발자

사용자의 일상에 실질적인 도움을 주는 모바일 애플리케이션을 개발합니다.

Android 네이티브 개발을 목표로 앱 개발 역량을 쌓고 있으며, Flutter 기반 AI 애플리케이션 개발과 API 연동 경험을 통해 모바일 서비스 개발에 대한 이해를 넓혀 가고 있습니다.

## 🛠 기술 스택

**Mobile**
- Android · Kotlin · Java · Jetpack Compose
- Flutter · Dart
- React Native

**Backend & Database**
- Spring Boot
- MySQL
- Firebase Authentication · Cloud Firestore · Realtime Database

**AI & API**
- OpenAI API
- Google ML Kit OCR

**Tools**
- Git · GitHub
- Android Studiod
- Figma

## 💡 주요 프로젝트
### 1. Popple
**Android 기반 팝업스토어 정보 제공 애플리케이션**
- Java와 XML을 활용한 Android UI 구현
- Firebase Realtime Database 기반 실시간 채팅 기능 개발
- 캡스톤디자인 경진대회 우수상
  
🔗[GitHub Repository](https://github.com/Kimdaeun0929/popple-android-firebase)

### 2. MindLog
**Flutter 기반 AI 감정 관리 애플리케이션**
- 팀장 및 PM으로 프로젝트 기획과 일정 관리, 핵심 기능 개발 주도
- OpenAI API를 활용한 감정 분석 및 맞춤형 케어 추천 기능 구현
- Firebase Authentication 및 Cloud Firestore 기반 사용자 인증과 데이터 관리
- 주간·월간 감정 통계 시각화 기능 개발
  
🔗[GitHub Repository](https://github.com/Hello11234567/MindLog)

## 🌱 개발 경험 및 성장
### TodoFriends | Kotlin · Jetpack Compose
AI 기반 소셜 일정 관리 Android 앱으로, Kotlin과 Jetpack Compose를 활용한 네이티브 프론트엔드 개발을 경험한 프로젝트입니다.

- Jetpack Compose 기반 Android UI 구현
- OpenAI API 연동 및 개인·팀 일정 추천 기능 구현
- 추천 결과 적용 및 재추천 기능 개발

현재 개발을 잠정 중단한 상태이며, Android 네이티브 개발 역량을 확장하는 과정에서 진행한 프로젝트입니다.<br/>
🔗[GitHub Repository](https://github.com/Hello11234567/TodoFriends)

### 마음이(Maeum) | Flutter · Spring Boot · MySQL 🚧
MindLog 프로젝트를 기반으로 일기 기능을 추가하고 통계 기능을 고도화했으며, Firebase 중심의 데이터 관리 구조를 Spring Boot와 MySQL 기반의 백엔드 구조로 확장한 개인 프로젝트입니다.

- Spring Boot · MySQL 기반 백엔드 설계 및 구현
- Flutter 앱과 REST API 연동
- 카카오 로그인 및 JWT 기반 인증 구조 개발
- 감정 기록, AI 분석, 일기 및 통계 기능 확장

서비스 출시를 목표로 개발 중이며, 앱과 서버의 연동 및 기능별 검증을 진행하고 있습니다.<br/>
🔗[FLutter GitHub Repository](https://github.com/Hello11234567/Maeum) [Server GitHub Repository](https://github.com/Hello11234567/maeum-server)
